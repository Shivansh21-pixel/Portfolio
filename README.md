# Shivansh Pandey — Portfolio v2

Minimalist monochrome Design-Engineer portfolio with custom Vector Core SVG favicon, HiDPI interactive ML/Systems labs, 1-click PDF resume download, OpenGraph social card, and mobile bottom dock.

## Files Included
- `index.html` — Semantic markup, OG/Twitter meta tags, inline project architecture SVGs, Resume modal & Mobile Dock
- `styles.css` — Monochrome Dark/Light system, film grain, 2px scroll progress bar, active nav pill & responsive layout
- `script.js` — HiDPI OlemoN PCA canvas (Top-K + sample queries), HiDPI NAFNet-Lite comparison slider, WireSpy 77-packet DPI with live search & ratio bar, scroll spy, `⌘K`/`/`/`T` shortcuts
- `favicon.svg` — Custom Vector Core monochrome SVG favicon
- `og-image.png` — 1200×630 OpenGraph & Twitter preview image
- `Shivansh_Pandey_Resume.pdf` — Direct 1-click downloadable PDF resume

## Quick Deploy
Upload this folder directly to **Vercel**, **Netlify**, or **GitHub Pages** — zero build step required.
